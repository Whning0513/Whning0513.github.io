Selected work

Work

Some of these are research code, some are tools. I keep them here because they helped me understand a problem a little better.

Research

ACAmodel ↗

Agent testing / code intelligence

A research codebase for studying how language-model agents find faults in programming submissions. It compares test-generation strategies, records coverage and verdicts, and keeps the experiment runner separate from model serving.

The useful question here is fairly simple: can feedback from a failed test help an agent find the next one?

Satellite ↗

Numerical computing / astrodynamics

An Earth–Moon gravity-assist and trajectory-design experiment. It combines patched-conic initialization, N-body Velocity–Verlet propagation, Horizons comparisons, and regression checks.

This is the project where I most often have to check whether a plausible picture is also a correct number.

Tools

deepseek-protocol-doctor ↗

Developer tool / agent protocols

An offline checker for DeepSeek-style tool loops and captured SSE or JSONL streams. It looks for mismatched tool-call identifiers, incomplete rounds, strict-schema problems, and lost reasoning content. It only inspects supplied data; it does not call a model.

Bathhub ↗

Numerical experiment / browser graphics

A browser-based shallow-water and SPH fluid experiment for a reef scene. The front end keeps the model interactive, while a separate backend is available for higher-resolution free-surface and near-wall experiments.

I wanted the surface motion to come from the solver rather than from a prerecorded animation.

Community

awesome-deepseek-skills ↗

Agent skills / reproducibility

A small catalog of Agent Skills that can be loaded by DeepSeek Harness. Each entry points to an immutable source commit, a license, and a static report, so the catalog can be checked before anything is installed.

The linked repositories contain the code and the current run instructions. Some experiments need local models or external data; the project READMEs describe those limits.
